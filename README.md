# Uyuyan Balık Rüya Yorumcusu

> Dünyanın ilk ve şimdilik tek **uyuyan balık rüya yorumlama** yazılımı.
> Bilim bunu istemedi. Biz yine de yaptık.

## Bu proje neden var?

Çünkü balıklar da uyur. Uyuyorlarsa rüya görürler. Rüya görüyorlarsa birinin bunu resmi bir dille yorumlaması gerekir. O biri bu depo oldu.

Bu yazılım:
- Gerçekten çalışır
- Hiçbir şeyi iyileştirmez
- Deniz hukukuna aykırı değildir (şimdilik)
- Lisansı "istediğin gibi gül ama faturayı bana kesme"dir

## Kurulum

```bash
git clone https://github.com/Tentivory/uyuyan-balik-ruya-yorumcusu.git
cd uyuyan-balik-ruya-yorumcusu
python3 ruya.py
```

İsim vermek isterseniz:

```bash
python3 ruya.py Hamsi Bey
python3 ruya.py "Büyük Kızıl Orkinos"
```

## Bilimsel yöntem

1. Rastgele bir yorum seçilir.
2. Ciddi bir yüzle ekrana basılır.
3. Kullanıcı inanmakta özgürdür.
4. Balık itiraz ederse suya yazılır.

Bu dört adım hakemli bir dergide yayınlanmamıştır. Hakemler henüz uyanmadı.

## Sık sorulan sorular

**Balıklar gerçekten rüya görür mü?**  
Evet. En azından bu depoda görürler.

**Yorumlar doğru mu?**  
Doğruluk, tuzluluk oranına göre değişir.

**Neden Türkçe?**  
Çünkü rüyalar da Türkçe görülünce daha inandırıcı oluyor.

**Siyasi bir mesaj var mı?**  
Hayır. (Evet ama bakma.)
